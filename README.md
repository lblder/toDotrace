# TodoAgent · 科研计划与学习轨迹

个人科研工作台：实验室打卡、计划待办、番茄计时与学习轨迹统计。
使用 React、TypeScript、Express 和 SQLite，支持多账号及邀请码注册。

## 为什么做这个项目？

最近，我一直在寻找一款适合自己的待办软件。试过一些产品后，发现它们很难同时满足我的几个需求：安排每天的任务、记录在实验室的时间，以及回顾自己真正投入了多少专注时间。

于是，我开始借助 AI，编写自己的 **每日待办工作台 toDotrace**。

### 1. 看见自己的时间用在哪里

待在实验室，并不意味着一直在学习。有时候，一坐就是几个小时，真正专注的时间却不多，剩下的时间可能都花在了刷手机上。

我希望通过每日打卡，记录到达、暂离和离开的时间，再结合任务的番茄计时，同时看见：

- **在场时长**：我在实验室待了多久。
- **专注时长**：我为任务实际投入了多少时间。
- **项目分布**：这些时间分别花在了哪些事情上。

这些记录可以帮助我发现分心的时段，逐步提高专注学习的比例。

### 2. 让学习过程远离手机

手机上已经有很多成熟、好用的番茄时钟软件。但对我来说，拿起手机设置计时器，也可能顺手打开短视频或社交软件。

这正是我选择做网页版的原因。

我希望在电脑上完成任务规划、开始计时和进度记录，让手机离开手边，减少学习过程中被打断的机会。

### 3. 为自己积累一份学习轨迹

最近，我开始关注一些数据 Trace 类项目：把日常行为记录下来，再结合具体场景进行分析和展示。

这让我想到，自己的学习过程也值得被记录。

通过持续积累任务、打卡和专注数据，我可以回顾每天的投入，观察一周的学习节奏，了解不同项目占用了多少时间，并按照自己的习惯设计统计方式和界面。

比起单纯勾掉一项待办，我更希望看见：**这些日常的小行动，是怎样一点点构成长期进步的。**

### 下一步：TodoAgent

toDotrace 也是我探索 **TodoAgent** 的起点。

目前，它负责记录任务、时间和完成情况。未来，我希望在这些真实记录的基础上，探索计划拆解、每日安排和学习复盘等辅助能力，让它逐渐成为一个了解我学习节奏的个人助手。

这个项目首先服务于我的日常学习，也欢迎有相似需求的人一起尝试和改进。

## 功能

- 到达、暂离、返回和离开记录，连续与累计打卡统计。
- 我的一天、重要任务、计划、项目管理及重复任务。
- 单任务专注计时，暂离或离开时停止计时。
- 完成日历、在场时长和按项目划分的专注统计。

## 开发与运行

需要 Node.js 22 或更高版本。

```sh
npm ci
npm run dev
```

单进程运行：

```sh
npm run build
npm start
```

默认服务端口为 8788。首次访问创建管理员，其他账号通过邀请码注册。
主机和端口可通过 `TODOAGENT_API_HOST`、`TODOAGENT_API_PORT` 设置。
macOS 可使用根目录的 `启动.command`。

## 验证

```sh
npm run typecheck
npm test
npm run build
npx playwright install chromium
npm run test:browser
```

`npm run verify` 顺序运行类型检查、测试、构建和浏览器测试。

## 数据与备份

数据保存在 `data/app.db`，该目录不进入 Git。
服务停止时可复制数据库；运行期间应使用 SQLite 一致快照，避免遗漏 WAL 中的数据。

## 当前限制

- 导入导出功能尚未完成，覆盖导入的事件语义仍有已知问题，不应作为可用功能使用。
- 部分打卡更正入口尚未接通。
- 浏览器自动化测试目前覆盖 Chromium。
- 超过 18 小时或顺序异常的到访时长标记为待核对，不计入时长统计。
- 持有效邀请码者可能通过注册反馈判断用户名是否已注册。
