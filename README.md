# TodoAgent · 每日打卡工作台

个人科研工作台：每日到实验室打卡、按微软待办模型管理日/周/项目计划、
规范化导入导出、热力图与四维综合评价。本地服务 + 多账号（邀请码注册），
数据全部保存在本机 SQLite，不依赖任何云服务。

## 当前状态

**设计阶段完成，尚未开始编码。** 三份基线文档：

1. [需求文档](./docs/01-需求文档.md) —— 做什么：打卡规则、计划模型（对齐微软待办 + 五项开源增强）、
   四层导入导出、热力图双状态切换与评分口径、账号与安全需求；
2. [架构设计文档](./docs/02-架构设计文档.md) —— 怎么搭：本地单服务形态、
   事件流水 + 投影的核心机制、账号隔离、时间口径、安全边界、部署形态；
3. [开发文档](./docs/03-开发文档.md) —— 怎么开发：技术栈、代码组织、七个阶段与验收标准、
   测试策略、决策记录（ADR）流程；

   登录鉴权时序、任务状态机、导入流程、分析管道——明暗主题、导览、可导出 PNG/SVG）。

另有 [决策记录](./docs/adr/)（ADR）：**ADR-001 ~ 007 已定稿**，承载编码前必须确定的机制级

## 规划的开发阶段

骨架与账号 → 核心域（时间/事件/重放）→ 打卡 → 计划 → 导入导出 → 分析与评价 → 打磨。
阶段 3 结束即可开始每日真实使用。详见开发文档 §3。
